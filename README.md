# 读者之刃 | Blade of Readers

点击链接游玩 ｜ click the link to play: https://cmdhl.github.io/blade-of-readers/

把晦涩的文章变成简单的平台跳跃游戏。\
Convert complicated articles into simple platformer levels.

上传 PDF 后，文字会变成可行走的平台。你可以攻击文字来选择文本，并复制、高亮或评论选中的内容。测验会召唤敌人：选中答案文本后，格挡敌人以回答问题。\
Upload a PDF and walk on its text. Attack text to select it, then copy, highlight, or comment on the selection. Quizzes will summon enemies: select the answer text and parry the enemy to answer.

特殊批注格式 / Special annotation formats:

```text
[msg|good|bad]Message text
[quiz]Question text
```

示例 / Examples:

```text
[msg|99|0]Contributions ahead
[quiz]What are the paper's main contributions?
```

good 和 bad 是编造的好评数与差评数，主打一个氛围感。\
good and bad are made-up vote counts for whether other imaginary players like it or not.

测验的高亮文本就是答案。\
For quizzes, the highlighted text is the answer.

这些内容只需要提前写进 PDF 批注里。你可以自己写，也可以请别人或 AI 帮你给 PDF 添加批注。\
These notes only need to be saved as PDF annotations ahead of time. You can write them yourself, or ask another person or AI to annotate the PDF.

推荐提示词 / Recommended prompt:

```text
Please annotate the PDF I uploaded and return an annotated PDF. Use PDF highlight annotations.

For messages, highlight short phrases or single words, then write the comment in this format:
[msg|good|bad]Message text
good and bad are made-up vote counts. Messages that are useful for reading comprehension usually deserve higher good counts, but you should also try to be funny.
Example: [msg|99|0]Contributions ahead

For quizzes, highlight the answer text, then write the comment in this format:
[quiz]Question text
Example: [quiz]What are the paper's main contributions?
```
